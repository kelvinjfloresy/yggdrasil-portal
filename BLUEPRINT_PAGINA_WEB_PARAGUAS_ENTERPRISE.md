## 4. INTEGRACIÓN Y CABLEADO CON EL KERNEL CENTRAL (`00_kernel_os`)

Para que la página web no sea un folleto estático, sino una **consola viva de la corporación**, el Kernel Central debe ejecutar una sola tarea:

1. **Exponer el archivo `runtime_status.json`:**
   - El script `watchdog_runtime.py` o el Kernel Central escribe el estado de los puertos cada 15 segundos en `portal_web/assets/runtime_status.json`.
2. **Consumo Frontend Transparente:**
   - La función JavaScript de la web:
     ```javascript
     async function fetchEcosystemTelemetry() {
       try {
         const resp = await fetch('assets/runtime_status.json?t=' + Date.now());
         const data = await resp.json();
         updateTelemetryPills(data);
       } catch (e) {
         console.log('Modo estático autónomo activo.');
       }
     }
     setInterval(fetchEcosystemTelemetry, 15000);
     ```
   - Si el Kernel está corriendo en la máquina de Kelvin, las tarjetas mostrarán automáticamente `🟢 ONLINE (0.8 ms)`. Si está en un servidor estático en la nube, mostrarán el estado de referencia certificado de forma elegante.
